# Fotografías de prueba

Esta carpeta puede contener fotografías de prueba autorizadas por quien las
proporcionó. No añadas imágenes privadas ni material sin licencia compatible.

Las pruebas automatizadas actuales generan imágenes sintéticas y verifican los
resultados del servicio con un clasificador controlado; no requieren fotografías
ni dependen de rutas absolutas. Para validar la precisión real del Haar Cascade,
incorpora fotografías pequeñas y con licencia adecuada y evalúalas localmente.
El detector puede tener falsos positivos y falsos negativos.
